# Code of Conduct

This public fork adopts the [MatrixArkAI community code of conduct](https://github.com/matrixarkai/TemporalStore/blob/main/CODE_OF_CONDUCT.md),
which follows Contributor Covenant 2.1. It applies to this fork's issue tracker,
pull requests, and project communications.

Be respectful, welcome different backgrounds and experience levels, and discuss
technical disagreements constructively. Harassment and disclosure of another
person's private information are not acceptable. Contact the project maintainers
about conduct concerns without posting sensitive personal details publicly.
